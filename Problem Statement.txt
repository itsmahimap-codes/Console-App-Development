Problem Statement

Managing customer bank account details manually is a tedious task. This requires the banks to have an efficient system so that all the customers’ details are maintained effectively and their balances are updated accordingly. Manual operations make it difficult to keep track of the customers’ records and alter the balance with every transaction.

Bank Management System is a console based application that was developed to facilitate some of the basic banking activities in a much more efficient manner. The application allows the user to open a new bank account, deposit and withdraw money, view all the account details and search an account by account number. This makes use of ArrayLists to store the account information and facilitates an easy and efficient method to manage all the records during run time.

This project helps to understand the underlying concepts of core java like object oriented approach, data structures and menu driven applications and provides sufficient knowledge that can help in developing basic banking related tasks in an efficient manner as compared to manual operations.
