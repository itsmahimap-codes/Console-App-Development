Project Title: Court Hearing Scheduling System

📌 Project Overview:
I have developed a console-based Java application that allows for the efficient and organized scheduling of court hearings.
This project was designed to simplify and make easier the management of information regarding cases, judges, lawyers, courtrooms, and hearing schedules, as well as ensure the prevention of overlapping of hearings and facilitate their control and viewing.

🎯 Objectives:
Organize and schedule court hearings.
Ensure storage of information on cases, judges, lawyers, and courtrooms.
Automate the process of scheduling court hearings according to availability.
Prevent overlapping of hearings.
Provide a convenient console-based interface for operating with court hearing schedules.

🚀 Features:
Case registration and management.
Judge management.
Lawyer management.
Courtroom management.
Assigning a court hearing.
Accessing a list of scheduled hearings.
Searching for cases and court hearings.
Rescheduling a court hearing.
Cancellation of a court hearing.
Checking of overlapping of hearings.
Viewing of upcoming hearings.

🛠️ Technologies:
Java
Object-Oriented Programming
Java Collections Framework
Git & GitHub
