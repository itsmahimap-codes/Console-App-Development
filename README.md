Project Overview:
I have created a console based java application to perform basic banking operations. The java application helps to manage the banking activities in an organized manner. It consists of various options to manage the customer accounts, perform deposit, withdrawal and other operations.

Objectives:
To create and manage the bank customer accounts.
To store the customer details and account information.
To perform deposit and withdrawal operations.
To search the account.
To display all the account details through menu driven console application.

Features:
Creation of customer account.
Depositing the amount into the account.
Withdrawing the amount from the account.
Searching the account based on the account number.
Displaying all the accounts.
Viewing the account balance.
Menu driven interface.
Storage of account records in dynamic data structure ArrayList.

Technologies Used:
Java
Object Oriented Concepts
Java Collections(ArrayList)
